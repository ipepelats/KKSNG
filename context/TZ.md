# Доработать ККСНГ_Курьер
Доработай ККСНГ_Курьер версии 0.57.2119 (интеграционный модуль ЭДО для работы в 1С от  Сбер документооборот / Сбер Корус.):
Нужно чтобы вместе с отправляемыми унифицированными ФНС счетами фактурами / УПД  автоматически подписывались и отправлялись имеющиеся соответствующие счета покупателям (объединить в пакет). 
Ссылка на соответствующий счет покупателю (счет на оплату) указывается в реализации. 
Большинство контрагентов работают с другими операторами ЭДО чем мы.
Моя версия - 1С:Предприятие 8.3 (8.3.27.1859),Бухгалтерия предприятия, редакция 3.0 (3.0.194.23)
Тип файла счета на оплату свободный.
Не придумывай методыиспользуй только существующие методы 1с
